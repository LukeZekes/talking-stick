# Talking Stick 0.26.0

Date: 2026-10-20

Any agent or person on this host can now see what every room is doing, and put a question to a
room's agents, without joining it. An assistant can answer "what is the clawdapus pair doing?"
from any folder. This is all CLI plus the skill; an MCP server was considered and deferred until
a client without a shell needs one (#120).

## Added

- `tt room list --all` lists every room on this host that has a live agent or console, most recent room activity first. For each room it shows the path and stable id, the agents and consoles, the stick holder (marked stale when the lease has expired), and a short excerpt of the last handoff. Listing never joins a room or refreshes anyone's presence (#121).
- `tt room brief <room>` shows what one room is doing without joining it: the stick holder or reservation, members and whether each is live, inactive, or gone, the latest handoff in full, the newest ten open notes with the real count, and the last 20 messages and handoffs (`--limit` up to 200). Clipped bodies and handoffs each carry a command that reads them whole, `--before` pages back through older events, and `updates_since` reads what arrives later. Name the room by short name, id, or path suffix from any folder (#122).
- Visitors can ask a room's agents a question without joining it: `tt room ask <room> --to <agent|room>`. Recipients see a `visitor` envelope whose header ends with `tt msg reply <request-id> --stdin`; their answers wake nobody in the room. The visitor reads answers with `tt room replies <request-id> --timeout 30` (at most 60 seconds), where an empty result with `timed_out: true` means no answer yet. Asking never joins, moves, or refreshes anyone, `--to room` reaches only live agents, and `--request-key` makes a retry return the original question even after its recipients leave (#123).
- The skill has a section on looking into other rooms and on answering visitors.

## Fixed

- `tt list` help said it lists rooms under a path; it lists the rooms whose scope covers the path.

## Upgrading

Run `tt self-update`, or let the daily automatic update install it. The first command opens the
database and applies migration 23, which adds the visitor request tables; older releases ignore
them. Restart running harnesses so agents load the new skill section, and reopen `tt chat`.
