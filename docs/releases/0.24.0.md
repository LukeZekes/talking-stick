# Talking Stick 0.24.0

Date: 2026-10-20

Two operator-console features: a role editor that shows who does what at a glance, and images pasted straight into chat.

## Added

- **Images in chat.** Ctrl+V attaches the clipboard's image (`osascript` on macOS, `wl-paste` or `xclip` on Linux). A paste with no text does the same; some terminals send one when the clipboard holds only an image. A pasted or dragged-in image path, or `/attach <file>`, attaches a file. The draft shows `[Image #N]`; delete the marker to drop the image. Keys typed while the clipboard is read wait, so Enter never sends the text without its image.
  - Images are copied to `<data dir>/attachments/<sha256>.<ext>`, with the extension taken from the bytes (PNG, JPEG, GIF, WebP; at most 8 per message, 20 MB each).
  - Each recipient's prompt gets one numbered line per image: `Image #1 attached at <path> (image/png, 415 KB). Read that file to see it.` Hook-based harnesses such as Grok carry only text, so an explicit read is what turns the path into pixels, and every harness gets the same line.
  - Before a message is accepted, the service checks that each named image is an intact file directly in the store: no links, and the size, type and hash match.
  - `tt msg send <to> [body] --attach <file>` (repeatable) sends images from scripts. The body may be empty when an image is attached.
- **`/roles` grid.** A fixed-size keyboard grid with role names as column headers, and a separate tab for harness defaults that apply in every room. Role definitions now live in the instruction files under `## Roles`. Definitions and the project instructions open in `$VISUAL`/`$EDITOR`. A preview shows which agents will be told what. Enter applies, Tab switches scope, and affected agents, including sessions in other rooms that inherit a changed default, are notified in their chats.
- `tt --version` prints the installed version (it used to print help).

## Upgrading

- From 0.23.1: `tt self-update`.
- From 0.23.0: run the install script again instead:

  ```bash
  curl -fsSL https://raw.githubusercontent.com/mostlydev/talking-stick/master/scripts/install.sh | sh
  ```

  `tt self-update` on 0.23.0 runs the installer that shipped with 0.23.0. That installer moves `~/.local/bin/tt` to the new release but leaves `<install-dir>/current`, and the skill links that go through it, on 0.23.0. The current script finishes the move.
